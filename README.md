# Overview

As a software engineer focused on continuous learning, I am building a foundation in C++ to strengthen my understanding of systems-level programming languages.
This is a simple console application that prints a greeting message to the screen. It demonstrates basic C++ syntax including the main function, standard output, and the use of the string class.

I created this software to confirm that my C++ toolchain, editor, and Git workflow are correctly configured before beginning larger projects this semester.

[Demo Video](https://youtu.be/NBZ54oVEsX8)

# Development Environment

- Visual Studio Code with the C/C++ extension
- g++ (GCC) compiler on Linux
- Git for version control
- Terminal : integrated VSCode terminal for compiling and running

Programming language: C++
